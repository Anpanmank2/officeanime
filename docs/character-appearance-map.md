# Character Appearance Map

Persona → appearance attributes for the 23 members currently defined in `jc-config.json`. This is
the content to design against when building individual parts/silhouettes under
`docs/persona-character-spec.md` (Route A, `docs/avatar-parts-tech-spec.md`).

**What this table is**: visual-design guidance only — hair, outfit silhouette, a couple of
accessories, and a one-line vibe — distilled from each member's role and working style in this
project's internal role-design references (not included in this repo). It exists purely to make
23 pixel-art characters look like 23 different people.

**What this table is not**: a biographical claim. "Presentation" is a design choice for silhouette
variety (which body/hair shapes to lean toward), not an assertion about a real person. "Age feel"
is a design band (how young/seasoned the character should *read*), not a literal age. Names,
department, and member ids are copied verbatim from `jc-config.json` (already public in this
repo) so the table lines up 1:1 with the runtime data.

Columns:
- **Member ID** — matches `jc-config.json`.
- **Name** — as it already appears in `jc-config.json` / `src/jc/persona-lines.ts`.
- **Dept** — department, as in `jc-config.json`.
- **Presentation** — a design lean for body/hair silhouette (not a biographical claim).
- **Age feel** — a design band, not a literal age.
- **Hair** — shape, length, texture/color lean.
- **Outfit** — top/bottom silhouette and overall styling.
- **Accessory** — 1–2 items max (the `accessory` slot caps at 2 in the tech spec).
- **Vibe** — one line capturing the character's on-floor presence (posture, energy, habitual
  gesture) — the thing a player should "feel" even before reading a name label.
